Install

Getting Context Compiler

Quick install (recommended)

One command installs the CLI and all dependencies.

curl -fsSL https://ctx-compiler.getaxiom.ca/install.sh | sh

Install options

FlagDescription
--versionPrint installer version and exit
--dry-runSimulate install without making changes

Manual install (from source)

If the installer fails, you can build from source.

# Install Rust (one-time) curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh source "$HOME/.cargo/env" # Clone and build git clone https://github.com/Mageester/context-compiler.git cd context-compiler cargo install --path . # Verify ctx --version
Tip: Building from source only requires Cargo/Rust. No AI API keys are needed.

Uninstall

# If installed via binary rm -f /usr/local/bin/ctx ~/.local/bin/ctx # If installed via Cargo cargo uninstall ctx # Remove config rm -rf ~/.ctx

Configure

Adding AI providers

Why configure?

The local pipeline (stages 1-4) works without any configuration. Add an API key to unlock Stage 5 AI reranking for maximum accuracy.

Set a provider

# OpenAI ctx configure --provider openai --api-key sk-... # OpenRouter (any model) ctx configure --provider openrouter --api-key sk-or-... # DeepSeek ctx configure --provider deepseek --api-key sk-... # Generic (self-hosted) ctx configure --provider generic --api-key any --base-url http://localhost:1234/v1

Show current config

ctx configure --show

Use ensemble reranking

Two providers vote independently on file relevance. If either marks a file CRITICAL, it jumps to the top. Enable with any provider set.

ctx configure --ensemble-rerank true

Workflow

How to use Context Compiler

The 3-step workflow

# 1. Index once cd ~/my-project ctx init # 2. Describe the task ctx "fix the missing import in App.tsx" # 3. Paste into your AI coding agent

Writing good tasks

Include filenames when you know them. Mention what you're trying to accomplish.
  • Good: "add tests for the payment webhook handler in billing.ts"
    Contains: task type (tests), module (billing), file hint (webhook handler)
  • Bad: "fix bug"
    Too vague — no context for the scorer to use

Token budgets

FlagDefaultUse when
-b, --budget8192Small focused tasks
16000Medium features, small modules
32000+Large refactors, multi-file features
-m, --max-files0 (auto)Hard cap on files selected

FAQ

Common questions

Do I need an API key?

No. The local pipeline (FTS5 BM25, filename boost, identifier matching, dependency propagation) works without any keys. Add a key to unlock Stage 5 AI reranking for ~16 percentage point boost.

Where is the index stored?

In .ctx/ at your project root. Add this to .gitignore. It contains index.db (SQLite) and cache files.

What file types are indexed?

Rust, TypeScript, JavaScript, Python, Go, Java, Ruby, C/C++, C#, PHP, Swift, Kotlin. Plus config files (JSON, YAML, TOML, .env) and markdown.

Why is my file not being selected?

Try reindexing with ctx reindex. If it still misses, the task description may be too vague. Mention the filename if you know it. For monorepos, include the subdirectory path in your task.

Clipboard doesn't work in SSH/headless?

Use ctx compile -o context.md "task" to write to a file instead.

How do I contribute or report issues?

Open an issue on GitHub. Contributions welcome.
