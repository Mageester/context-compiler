How to use Context Compiler in plain English

This page is the short version. It shows what the tool does, what commands to run, and what you should expect to see. No jargon. No guesswork. Just the steps.

Start here See commands

What it does

You describe the job. Context Compiler picks the important files. Then you paste that result into your coding AI.

In one sentence

It saves you from hunting through a whole repo by hand.

What you get

  • A short list of important files
  • A token-budgeted context pack
  • Optional AI reranking for better accuracy

Before vs after

1

Before: open the repo, guess which files matter, copy too much, forget one important file, and waste time.

2

After: run one command, get a clean file list, and paste it into your AI.

How to use it

1
Open a project folder.

Go to the root of the codebase you want to work on.

2
Build the index once.

Run ctx init. This scans the repo and saves a local index in .ctx/.

3
Ask for the thing you want.

Example: ctx "fix the missing import in App.tsx"

4
Read the result.

It shows the best files, sorted by relevance.

5
Paste it into your AI.

The output is already trimmed and ready for a coding assistant.

Commands you’ll use most

ctx init
ctx "fix this bug"
ctx compile --budget 12000 "update the login flow"
ctx status
ctx reindex
ctx configure --api-key YOUR_KEY

If you only remember one command, remember ctx "what you want".

What each command means

  • ctx init = scan the repo once
  • ctx "task" = find the important files
  • ctx compile = same thing, but with more control
  • ctx status = show index health
  • ctx reindex = rebuild everything from scratch

Simple picture of the workflow

How to know it worked

Good signs:

  • You see a short list of files, not the whole repo.
  • The top files look related to your task.
  • The output fits inside your token budget.

If it looks wrong:

  • Run ctx reindex.
  • Try a clearer task description.
  • Use ctx configure --api-key ... for better reranking.

When to use API mode

If you want better ranking, give it an API key and model settings.

ctx configure --provider openrouter --api-key YOUR_KEY
ctx configure --reranker-model openai/gpt-4o-mini
ctx configure --embedding-api-base https://api.openai.com/v1
ctx configure --reranker-api-base https://openrouter.ai/api/v1
