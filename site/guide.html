Workflow

The clean path from task to context.

Run the index once, describe the work in plain English, then let Context Compiler rank and trim the files that matter. The result is a paste-ready context pack that stays aligned with the repo instead of your memory.

01

Index the repo

Run ctx init at the project root to build the local SQLite index.

02

Ask in plain language

Use ctx "describe the bug or feature" and include file names when you already know them.

03

Paste the result

Take the selected context and drop it into your coding agent, editor, or review workflow.

ctx init

Create or refresh the local index for the current repository.

ctx "task"

Shorthand mode for the default token budget and ranking pipeline.

ctx compile

Use flags like -b and -m when you need tighter budgets or more files.

ctx status

Inspect what is indexed, what was selected, and how the current repo is configured.
