Install

One command. Any provider.

The installer downloads a release binary when one exists. Until public releases are cut, it automatically falls back to building from GitHub source with Cargo.

v0.3.0 adds support for OpenAI, OpenRouter, DeepSeek, and GitHub Copilot Codex — plus ensemble reranking that calls multiple providers and votes on the best files.

install.sh
curl -fsSL https://ctx-compiler.getaxiom.ca/install.sh | sh

# then, inside any repo
ctx init
ctx "add tests for the payment webhook"

# configure your provider
ctx configure --set-provider deepseek --set-deepseek-key sk-...
ctx configure --set-ensemble-rerank true

Architecture

5-stage ranking pipeline.

Context Compiler doesn't guess. Every file goes through a multi-stage scoring engine that combines lexical search, filename matching, identifier analysis, dependency graph propagation — with an optional ensemble AI reranker that uses multiple providers for maximum accuracy.

1

FTS5 BM25

SQLite full-text search over file paths, summaries, and extracted code identifiers. Uses BM25 ranking with prefix matching so "auth" matches "authentication".

always active

2

Filename boost

If the task explicitly names a file (App.tsx, repos.ts), those files get a hard score boost. Exact path matches get the highest priority.

always active

3

Identifier match

Compound code identifiers (CamelCase, snake_case) are extracted from every file. Files whose identifiers match task terms get a strong relevance boost — perfect for finding function-named files.

always active
→
4

Dependency + history

Import graph propagation boosts files related to high-scoring matches. Past task history amplifies patterns you've touched before.

always active
→
5

AI ensemble reranker

Optional multi-provider pass scores the top 30 candidates. In ensemble mode, 2 providers vote independently and results are merged — a file marked CRITICAL by either gets max priority.

requires API key

Providers

Bring your own AI.

v0.3.0 supports 4 AI providers for embeddings and reranking. Use whichever you already have a key for — no vendor lock-in.

OpenAI

Default provider. Uses text-embedding-3-small for embeddings and gpt-4o-mini for reranking. Set via OPENAI_API_KEY or ctx configure --set-openai-key.

default

OpenRouter

Route through openai/text-embedding-3-small for embeddings and openai/gpt-4o-mini for reranking. One API key gives access to hundreds of models.

multi-model

DeepSeek

Use deepseek-embedding for embeddings and deepseek-chat for reranking. Fast and cost-effective for code tasks.

fast & cheap

GitHub Copilot Codex

Automatically detects Codex OAuth credentials from ~/.hermes/auth/. Zero configuration — works if you use Hermes with Codex.

auto-detect

FTS5 + prefix matching

SQLite full-text search with BM25 ranking, compound identifier indexing (CamelCase + snake_case), and intelligent prefix matching. Every searchable signal from your codebase, normalized to 0-1 min-max scores.

Smart trimming

Keeps types, signatures, and logic while removing obvious boilerplate and comments. Files are trimmed to fit your exact token budget.

AI ensemble reranking

Two providers score the same candidates independently. Results are merged by consensus — if either model calls a file CRITICAL, it jumps to the top. Far more reliable than a single model pass.

Provider-agnostic

Set one key or four. The tool auto-detects which providers are configured via env vars, config files, or OAuth credentials. Run ctx providers to see your available options.

Quickstart

  1. Install with the command above.
  2. Open your codebase root.
  3. Run ctx init.
  4. Run ctx "describe the feature or bug".
  5. Paste the generated context into your coding agent.

Commands

  • ctx init — create the local index.
  • ctx "task" — shorthand compile with default budget.
  • ctx compile -b 16000 -m 8 "task" — custom token budget and file limit.
  • ctx configure --set-openai-key=sk-... — set provider API key.
  • ctx configure --set-provider=deepseek — switch AI provider.
  • ctx providers — list all configured providers.
  • ctx reindex — rebuild from scratch.
  • ctx history / ctx done — view and save task history.
  • ctx watch — periodically rebuild while files change.

Providers

v0.3.0 supports four providers. Set any combination of API keys via ctx configure or environment variables:

  • OpenAI: OPENAI_API_KEY or --set-openai-key
  • OpenRouter: CONTEXT_COMPILER_OPENROUTER_KEY or --set-openrouter-key
  • DeepSeek: CONTEXT_COMPILER_DEEPSEEK_KEY or --set-deepseek-key
  • Codex: Auto-detected from ~/.hermes/auth/openai-codex-oauth-1.json

When --set-provider=auto (default), the tool tries providers in order: OpenAI → DeepSeek → OpenRouter → Codex → hash fallback.

Ensemble Mode

When enabled, the AI reranker calls 2 providers independently on the same candidate set. Results are merged by averaging scores — but any file marked CRITICAL by either provider gets a final score of 1.0. This catches cases where one model misses a subtle dependency that another catches.

Enable with: ctx configure --set-ensemble-rerank true

Recipes

ctx "find where user sessions are created"
ctx compile --budget 12000 --output context.md "refactor payment webhook"
ctx configure --set-provider=deepseek --set-deepseek-key=sk-... && ctx reindex && ctx compile "add auth middleware"

Troubleshooting

  • If install says Cargo is missing, install Rust from rustup and rerun.
  • If output seems stale, run ctx reindex.
  • If clipboard access fails in a headless shell, use ctx compile -o context.md "task".
  • Do not commit .ctx/; it is local cache data.
  • If FTS errors occur with special characters, upgrade to v0.3.0 which fixes the BM25 normalization bug.
