Architecture

4-stage ranking pipeline.

Context Compiler doesn't guess. Every file goes through a multi-stage scoring engine that combines lexical search, semantic embeddings, filename matching, and dependency graph analysis — with an optional AI reranker for premium accuracy.

1

FTS5 BM25

SQLite full-text search over file paths, summaries, and extracted code identifiers. Uses BM25 ranking with OR matching so files that match more task terms rank higher.

always active
→
2

Filename boost

If the task explicitly names a file (App.tsx, repos.ts), those files get a hard score boost. Exact path matches get a 0.5 boost; partial matches get 0.3.

always active
→
3

Semantic + dependency

Hash-based embeddings (or real OpenAI embeddings when configured) measure task-to-file similarity. Import graph propagation boosts files related to high-scoring matches.

always active
→
4

AI reranker

Optional GPT-4o-mini pass scores the top 30 candidates against the actual task. Labels each file CRITICAL / HIGH / MEDIUM / LOW / SKIP. This catches semantic intent that no algorithmic approach can match.

requires API key

FTS5 lexical engine

SQLite full-text search with BM25 ranking, compound identifier indexing (CamelCase + snake_case), and path-aware tokenization. Every searchable signal from your codebase.

Smart trimming

Keeps types, signatures, and logic while removing obvious boilerplate and comments. Files are trimmed to fit your exact token budget.

AI-powered reranking

Optional GPT-4o-mini pass scores top candidates against your actual task. Catches semantic intent that no algorithmic approach can match. Set your OpenAI key via ctx configure.

Filename + dependency aware

Mentions a file by name? It gets a hard boost. High-scoring file's dependencies? They get pulled up too. The import graph is fully indexed.

Quickstart Commands Recipes Troubleshooting

Quickstart

  1. Install with the command above.
  2. Open your codebase root.
  3. Run ctx init.
  4. Run ctx "describe the feature or bug".
  5. Paste the generated context into your coding agent.

Commands

  • ctx init — create the local index.
  • ctx "task" — shorthand compile with default budget.
  • ctx compile -b 16000 -m 8 "task" — custom token budget and file limit.
  • ctx status — show indexed files/languages/history.
  • ctx configure --set openai-key=sk-... — set API key for AI reranker.
  • ctx reindex — rebuild from scratch.
  • ctx history / ctx done — view and save task history.
  • ctx watch — periodically rebuild while files change.

Recipes

ctx "find where user sessions are created"
ctx compile --budget 12000 --output context.md "refactor payment webhook"
ctx reindex && ctx status

Troubleshooting

  • If install says Cargo is missing, install Rust from rustup and rerun.
  • If output seems stale, run ctx reindex.
  • If clipboard access fails in a headless shell, use ctx compile -o context.md "task".
  • Do not commit .ctx/; it is local cache data.
