# Context Compiler Launch Kit

## One-liner

Describe the coding task once. Get the exact files your AI coding agent needs — ranked, trimmed, and ready to paste.

## Positioning

Context Compiler is the missing prep step before Cursor, Claude Code, Codex, Copilot Chat, or ChatGPT. It saves developers from manually hunting through a repo before every AI coding session.

## Install

```bash
curl -fsSL https://context-compiler.pages.dev/install.sh | sh
```

## Primary audience

- Cursor users
- Claude Code users
- Codex/Copilot users
- indie hackers
- dev agencies
- teams with large repos
